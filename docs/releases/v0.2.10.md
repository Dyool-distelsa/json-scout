# JSON Scout v0.2.10

## Highlights

- Reorder document tabs by dragging them, or with Alt+Shift+Left/Right on a focused tab. Reordering does not change the documents.
- **Split editor** opens a second editor group beside the first, each with its own tabs. Drag a tab from one group to the other to read two documents side by side, for example when comparing.
- Toolbar actions, Save, Close and Diff apply to the focused group. Moving a tab keeps its document state; closing the last tab of the second group returns to a single editor.

## Validation and boundaries

- 924 JavaScript tests (including real-editor DOM tests for split, movement, close and Diff) and the production frontend build passed. The release workflow runs the repository's Windows/Linux CI, including Rust tests.
- Drag between groups was exercised in jsdom, not in the desktop app by an independent tester.
- Windows and Linux installers are built by the release workflow. macOS remains experimental and is not included. Windows installers remain unsigned.

See the [installation runbook](../installation.md). Before updating or closing the app, protect any saved but unpushed Vault edits: its working workspace is cleared at startup and window close.
