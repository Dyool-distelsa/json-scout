# JSON Scout v0.2.7

## Highlights

### See what changed
- Click a file in the **Changes** list (or right-click → **Show Changes**) to see what changed since the last commit: key by key for JSON, line by line for invalid JSON, with the values shown.
- Deleted and new files can be inspected too, and the right-click menu also offers **Open** and **Compare with active tab**.

### Files panel actions
- Right-click a file to **Duplicate** it (`name copy.json`, `name copy 2.json`, …) or **Rename…** it.
- Right-click a folder for **New JSON file…**, **Rename…**, and **Format**, **Minify** or **Sort keys** in all its JSON files, subfolders included, after a confirmation. Invalid files are reported and left untouched, and files with unsaved edits are skipped.
- Existing files are never overwritten. Open tabs follow a rename and reload after a bulk change, and rescanning a folder keeps expanded folders open.

### MongoDB-style queries
- The **Query** panel accepts `{ … }`, `find(…)` and `db.<collection>.find(…)`. JSONPath (`$..author`) and bare key names still work.
- Filter operators `$eq $ne $gt $gte $lt $lte $in $nin $exists $regex $size $all $elemMatch $type $not` and `$and $or $nor`, with dotted paths into arrays as in MongoDB.
- Shell syntax (unquoted keys, single quotes, `/regex/i`, `ObjectId("…")`, `ISODate("…")`), projection, and `.sort()`, `.skip()`, `.limit()`, `.count()`.
- The input is multi-line (Enter runs, Shift+Enter adds a line), a summary shows how many documents matched, and each result shows its JSONPath. At most 500 results are drawn.

### Large files
- Files up to 512 MB open (the limit was 64 MB).
- A loading overlay shows the file name and the current step while a large file opens.
- Editing large documents is much faster: one native parse is shared by the status bar, panels and linter, Stats only render while shown, and very large documents wait a little longer after an edit before re-parsing.
- The editor's scrollbars are wider (18 px) and easier to grab.

## Notes
- Windows installers remain unsigned; SmartScreen may warn.
- Platform status is unchanged: Windows and Linux are stable, and macOS remains experimental and is not included in this release.
