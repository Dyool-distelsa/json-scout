# JSON Scout v0.2.3

JSON Scout v0.2.3 adds safer Vault diagnostics for supported Windows and Linux builds.

## Highlights

- View the latest Vault diagnostic after a transient toast expires.
- Copy a secret-safe diagnostic report on demand.
- Use the displayed report fallback when clipboard access is unavailable.
- Keep diagnostics session-only: reports are not written to disk or published automatically.

## Platform support

- **Supported:** Windows and Linux.
- **macOS:** Not supported yet. A separate official macOS release requires signed and notarized artifacts plus the remaining Apple/build-validation prerequisites. No macOS workflow changes are included here.

## Verification status

Automated tests and the Windows MSI/NSIS build are part of release verification. Manual desktop smoke testing remains pending, and native review is unavailable in this environment; those limitations are reported honestly rather than treated as completed validation.
