# JSON Scout v0.2.8

## Highlights

- Open and edit `.md` and `.markdown` files alongside JSON, including from the Files and Changes panels.
- Switch between JSON and Markdown modes. Markdown supports Raw, Split and Preview views, a heading outline and word counts.
- Markdown previews sanitize rendered content before displaying it.
- New files and empty tabs inherit the active mode: Markdown creates `.md` files and proposes `untitled.md` when saving.
- Switching to a saved tab detects its extension again and updates the editor, toolbar and Markdown preview.
- Renaming or saving a file with another supported extension updates its mode.

## Validation

- 893 JavaScript tests passed; production frontend build passed.
- Windows and Linux installers are built by the release workflow. macOS remains experimental and is not included.
