# JSON Scout v0.2.9

## Highlights

- Identify the loaded Vault environment with a persistent DEV / QA / STG / PROD badge, top stripe and native window-title prefix. Names ending in `-main` mean PROD; unrecognized names show UNKNOWN rather than DEV.
- Scrollbar thumbs, including the editor's, and a dot on the logo follow the loaded environment in both themes. The logo has a short, non-looping entrance animation that respects reduced-motion preferences.
- Every valid **Load** clears the previous Vault list and search filter before requesting the next list, including when reloading the same vault. Invalid names leave the current list and filter unchanged.
- Switching vaults resets only the panel: it does not delete downloaded files or close documents. Pulled tabs retain their original vault's environment label and colored top edge after another vault is loaded.
- Manual **Clear** keeps its existing cleanup behavior and confirmation for unpushed changes.

## Validation and boundaries

- 916 JavaScript tests and the production frontend build passed for the 0.2.9 release candidate. The release candidate also runs the repository's Windows/Linux CI, including Rust tests, before publication.
- Independent source/controller probes passed. The separate scratch panel test run could not start because its dependencies were unavailable; actual desktop pixels and native window-title execution were not independently validated. Native RDD was unavailable because its local binary was missing.
- Environment is inferred from vault naming, not verified against Azure infrastructure or permissions. The header describes the loaded target, while each pulled tab describes its original vault.
- Windows and Linux installers are built by the release workflow. macOS remains experimental and is not included in this release. Windows installers remain unsigned.

See the [installation runbook](../installation.md) and [Azure Key Vault guide](../azure-key-vault.md). Before updating or closing the app, protect any saved but unpushed Vault edits: its working workspace is cleared at startup and window close.
