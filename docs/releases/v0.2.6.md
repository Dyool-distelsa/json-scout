# JSON Scout v0.2.6

## Highlights

### Open a folder
- **File > Open Folder…** picks a folder, and the **Files** panel shows every `*.json` file under it as a collapsible tree. Subfolders without JSON, hidden folders and `node_modules`, `target`, `dist` and `build` are left out. Very large folders are cut short, and the panel says so.
- Folders opened from Explorer (**JSON Scout here**) use the same tree.

### Git changes
- When the opened folder is inside a git repository, a **Changes** section under the tree lists its changed JSON files with a badge: **M** modified, **A** added, **D** deleted, **R** renamed, **U** untracked, **!** conflict.
- It refreshes when you save and when the window gets focus back. Outside a git repository, or without git installed, it stays hidden.

### Right-click menus
- Right-click a file in the tree or in Changes to **Open** it or **Compare with active tab** in Diff mode.
- Right-click a tab to **Close**, **Close All**, **Close to the Right** or **Close to the Left**. Tabs with unsaved changes still ask first, and **Cancel** keeps the rest open.

### Azure Key Vault
- Pushing a JSON secret now validates it, sorts its keys and minifies it. Reordering keys alone no longer counts as a change, and JSON made invalid after the preview cancels the push.

## Notes
- Windows installers remain unsigned; SmartScreen may warn.
- Platform status is unchanged: Windows and Linux are stable, and macOS remains experimental and is not included in this release.
